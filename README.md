# Multiplayer Element Discovery and Combination System

**DBMS Mini Project**

## Abstract
A web-based element combination game where players discover new elements, earn XP, unlock achievements, complete challenges, and compete in timed multiplayer battles.

## Project Files
The `element-discovery-game/` folder contains the complete frontend, backend, and database implementation. The ER Diagram, Relational Schema, and Project Report are provided separately.

## Databases Used
- **MySQL:** Stores users, elements, recipes, discoveries, battles, and achievements using relational tables, procedures, triggers, and views.
- **MongoDB:** Manages activity logs, game sessions, and flexible element metadata.

## Outcome
Developed a functional multiplayer game demonstrating SQL–NoSQL integration, database operations, player progression, and multiplayer gameplay.

## Project Originality
The project extends traditional element-combination games through persistent discoveries, XP progression, achievements, challenges, leaderboards, and timed asynchronous multiplayer battles.
